To run the FastAPI backend server on Windows, follow these steps:

1. Open your terminal (PowerShell or Command Prompt).
2. Ensure you are in the root directory of the project:
   cd c:\Users\legit\OneDrive\Desktop\RESUME_PPROJECT1

3. Set up the Python virtual environment (only needed the first time):
   cd backend
   python -m venv .venv

4. Activate the virtual environment:
   .\.venv\Scripts\activate

5. Install the required dependencies:
   pip install -r requirements.txt

6. Set up your environment variables:
   Copy `.env.example` to `.env` in the root directory, and fill in your API keys.

7. Start the server from the root directory:
   cd ..
   uvicorn backend.app.main:app --reload --port 8000

The server will now be running at http://localhost:8000
