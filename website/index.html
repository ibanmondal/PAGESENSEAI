Features

What PageSense does

Four core capabilities. Zero bloat.

Multi-Tab Ingestion

Index your open browser tabs and PDFs in one click. Clean content extraction strips boilerplate, ads, and navigation — only the main content gets indexed.

Hybrid Retrieval

BM25 (lexical) + dense embeddings (semantic) fused via Reciprocal Rank Fusion, then re-ranked by a fine-tuned cross-encoder for maximum precision.

Citations + Confidence

Every answer cites its sources with clickable links. A confidence score derived from re-ranker scores tells you how grounded the answer is.

Eval Harness

Unit-tested metrics (nDCG, MRR, MAP, Recall@k) and a reproducible before/after experiment on a labeled dataset with hard negatives.

Architecture

How it works

Three stages. Clean separation. Each one independently evaluable.

1

Extract & Chunk

Content scripts pull clean text from each tab. A paragraph-aware chunker splits documents into ~400-token pieces with overlap, so boundary terms aren't lost.

2

Retrieve & Re-rank

BM25 + dense embeddings retrieve top-20 via RRF fusion. A cross-encoder re-ranks to top-5 — the expensive but accurate second stage that every serious RAG system needs.

3

Generate & Verify

A LangGraph agent (retrieve → generate → fact-check) routes to Gemini Flash (cheap) or GPT-4.1 (hard). Answers come with numbered citations and a confidence score.
